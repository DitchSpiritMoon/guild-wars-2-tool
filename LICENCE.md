## 🧩 About

**Guild Wars 2 Tool** is a comprehensive overlay and utility for Guild Wars 2 featuring DPS meter, build templates, event timers, trading post helper, and customizable UI.

Based on popular tools like **ArcDPS**, **GW2TacO**, and **Blish HUD**.

---

## ✨ Features

### 🎮 Core Tools
- DPS Meter — real-time damage and healing statistics
- Build Templates — save and load trait and skill builds
- Event Timers — track world bosses, meta events, and festivals
- Trading Post Helper — price checks and profit calculations
- Overlay — customizable HUD with compass and markers

### 🎨 Interface & Customization
- Custom UI — resizable windows and themes
- Hotkey Support — bind actions to keys
- Minimap Markers — add personal waypoints and notes
- Chat Overlay — filter and highlight messages

### 🏋️ Utility & Automation
- Auto Loot — automatically collect loot from fallen foes
- Inventory Manager — sort and compact items
- Session Tracker — log playtime and earnings
- API Integration — sync with official GW2 API for account data
